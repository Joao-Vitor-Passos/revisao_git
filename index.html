Principais Atalhos do Visual Studio Code

Lista de apoio aos atalhos mais utilizados durante o desenvolvimento:

  • Ctrl + S: Salvar o arquivo atual
  • Ctrl + Z: Desfazer a última ação
  • Ctrl + Shift + P: Abrir a Paleta de Comandos
  • Ctrl + ': Abrir ou fechar o terminal integrado
  • Ctrl + F: Localizar texto no arquivo
